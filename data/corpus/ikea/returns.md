# IKEA US — Returns & Claims

## Return windows
- **New / unopened products:** 365 days with proof of purchase.
- **Open products:** 180 days with proof of purchase.
- **Mattresses:** may be exchanged for another mattress one time within 90 days.

## Refund method
Refunds are made in the same form of payment originally used to make the purchase. Only the net purchase price shown on the receipt is refunded.

## Non-returnable items
IKEA does not accept returns on:
- Plants
- Cut fabric
- Custom countertops
- As-is products

## Return conditions
IKEA cannot process refunds or exchanges if merchandise is modified from its original form when purchased, dirty, stained, or damaged.

## How to return or exchange
Customers must present:
- Receipt
- Valid government-issued photo ID (ID information is retained in a company-wide database used only for authorizing returns).

## Additional terms
- Returns are not accepted at IKEA Planning Studio or Pick Up Point locations.
- Promotional item values are deducted if the promotional item is not returned with the original purchase.
